REST → MCP 工具

名称MethodPath最高数据等级等级Token

存量 REST 接口按「方法 + 路径模板 + 参数 schema」注册为工具，以 rest.工具名 出现在 /mcp 的 tools/list 中；路径 {{参数}} 会被替换转义，其余参数走 query（GET/DELETE）或 JSON body（POST/PUT/PATCH），调用前做参数 schema 校验、等级授权与 DLP，凭据加密存储、永不回显。

Prompt 模板库

名称状态版本范围最高数据等级等级

模板走提交 → 审核 → 发布：新版本只追加不改旧版，发布后才对 Agent 可见；回滚就是把旧版本重新发布。Agent 经 /mcp prompts/get 读取已发布版本，参数先过 DLP，渲染结果再过 DLP + 自带级脱敏。

文件夹知识库

名称路径最高数据等级文档最近扫描

指定共享文件夹即自动索引其中的 .md / .txt / .docx / .pdf，按文件夹映射密级；增量更新只索引变化文件。Agent 经 /mcp 按「目录 → 章节树 → 章节原文」渐进式取用，引用精确到文件 + 章节 + 页码；摘要为抽取式（章节首句），不经过模型，不产生泄漏通道。
