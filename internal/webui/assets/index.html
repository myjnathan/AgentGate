响应缓存

仅缓存公开/内部、无敏感内容的非流式回答（精确匹配整份请求）；命中不计上游用量，审计记为 cache_hit；缓存只在内存中，重启即清空。

OpenTelemetry 导出

网关与 MCP 调用产生脱敏的 trace 与指标（OTLP/HTTP JSON），默认关闭；设置 OTEL_EXPORTER_OTLP_ENDPOINT（如 http://localhost:4318）后导出到 Jaeger / Tempo / Phoenix 等后端。Span 只含模型、渠道、密级、处置、Token 数等元数据，绝不含提示词、工具参数或模型回复。

审计日志

全量事件以哈希链追加写入，任何篡改都会使链校验失败；可导出 NDJSON 或按保留期归档。

导出文件可直接喂给 jq / SIEM，响应头附带哈希链校验结果；归档把超过保留期（默认 180 天）的事件移入 gzip 压缩包并留校验锚点。

文件夹知识库

添加文件夹

支持 .md / .txt / .docx / .pdf，增量更新只索引变化文件；引用精确到文件 + 章节 + 页码。摘要为抽取式（章节首句），不经过模型，不产生泄漏通道。

语义索引（FRAS）

每份文档的每个章节一行语义条目（职责 / 关联 / 适用范围 / 硬约束）加标签坐标（部门 / 类型 / 重要度），作为目录层供 Agent 判断相关性；每条带原文回指（文件 + 章节 + 页码）。默认抽取式生成，绝密文档只登记标题。
