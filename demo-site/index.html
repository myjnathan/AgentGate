守的不是 Agent，是三道门

桌面 Agent 正在变成像浏览器一样的通用品，换代很快；不变的是公司的数据、系统和责任。AgentGate 不做 Agent 本身，只守住三道必经之门：

模型门

模型网关

所有模型调用走 OpenAI 兼容网关：数据分级判定、敏感词与隐私脱敏、按人/部门配额与限流、渠道健康与故障切换，全量审计。

能力门

能力网关

公司的数据与系统只以受授权的 MCP 工具形式开放，凭据托管在网关侧、永不下发到员工电脑；外部知识库与系统也可经标准协议接入，同样过这道门。

数据门

分级与脱敏

公开 / 内部 / 机密 / 绝密四级，按渠道信任类型选路：机密默认脱敏后上云、原文不出公司；绝密只走本地模型或直接拦截，并明说原因。

在线演示：5 分钟看完核心故事

演示站内置一家虚构公司「星河精密」（医疗器械）的完整数据。按下面四步点一遍，就能看到 AgentGate 最重要的区别——同一个问题，自带 Agent 被拦，受管 Agent 脱敏放行：

1

看总览

用管理员账号登录，先看总览页：调用、拦截、按部门用量与处置分布。

2

找两条拦截

打开「审计日志」，找标着 block 的行：员工用自带 Agent（byoa）询问机密项目 XH-200、发送敏感词，都被当场拦下。

3

看一条放行

同样在审计里找 reroute：受管 Agent（managed）问同一个机密问题，经脱敏通道放行——能干活，但原文不出公司。

4

导一份报表

打开「合规报表」，把本周报表导出 CSV——给等保 / 保密评审看的周期报表，只含统计，不含敏感原文。

核心能力

为传统保守公司设计：不假设你有自有模型、数据库或知识库——都没有，也能从第一天用起来；已经有的现代家底（知识库、MCP 服务）也能接进来。

分级路由 + 可逆脱敏

按数据等级与渠道信任类型选路；脱敏用可逆占位符，云端只见代号、响应自动还原，流式输出同样处理。

文件夹即知识库

把共享文件夹指给它即可：自动索引成三层 Wiki（目录 → 摘要 → 原文按需下钻），引用精确到文件 + 章节 + 页码，不需要向量库。

Agent 证明与终端盘点

受管 Agent 登录时提交版本 / 配置 / 插件证据，平台核验通过才发受管级令牌；终端持续心跳盘点，配置漂移标红。

端侧隐私网关

员工电脑上的本地 sidecar 在请求出门前先扫一遍：隐私与凭据本地脱敏、映射不出本机；断网时按缓存策略执行，高密级默认拦截。

例外审批流

被拦的高密级调用可以申请例外：理由 + 范围 + 时效，管理员审批后发一次性放行凭证，全程审计；绝密默认不可例外。

组织同步与分发

钉钉 / 飞书 / 企业微信组织架构同步与身份绑定；受管 Agent 安装包由平台托管分发、支持离线导入，包哈希自动成为证明基准值。

合规周期报表

按周 / 月生成评审报表并导出 CSV，与实时告警 Webhook 一起，让「审计有人看」落到实处。

技能与 Prompt 治理

技能（Skills）与 Prompt 模板集中发布、审核、按部门与密级授权，员工端一次接入、统一令牌。

路线图

语义复核层（已立项）

在规则检测之上增加可选的语义研判层，识别变相表达、拆分、编码类绕过；复核通道本身同样走分级路由，绝密不送审。

部署：一个文件，三步

单二进制 + 一个数据目录，不装数据库、不配 Python/Node 环境。保守模式预设开箱即用：机密以上默认拦截、审计全开；上线路径先观察（只审计不拦截）、再提醒、后拦截。

1 · 下载

从 GitHub Releases 取对应平台的二进制，或用 Docker / 离线包部署。

2 · 运行

设置主密钥后直接启动，管理台、模型网关、MCP 网关都在这一个进程里。

3 · 接入

员工用设备码登录一次，生成统一令牌；DSH、Claude Code、Codex 等 Agent 按标准协议接入。

弱点明说

我们只防「电脑内」的数字数据流

员工拍照、默记、口述把信息带出公司，不在任何软件的防护范围内——那是贵公司保密制度的事，我们不假装能防。同时明说当前的技术边界：

  • 规则检测看的是「词」，不是「意思」：变相表达、拆分、编码过的外发可能漏检（语义复核层已立项，见上）；
  • Agent 证明是软件自报证据：能防配置漂移与误装，防不住蓄意伪造——受管终端仍需收回员工本地管理员权限；
  • 签约云的「零留存、不训练」是合同承诺而非技术保证，所以机密默认先脱敏再上云；
  • 网关目前是单点：双机热备在路线图上，排在核心治理功能之后。

完整的弱点清单与对策随版本持续更新——我们相信把边界讲清楚，比把功能吹满更值得信任。
