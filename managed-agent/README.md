# 受管 Agent 包（Managed Agent）

基于 DSH 上游的企业受管构建。原则：**不 fork 内核**，只做配置锁定、
构建签名与分发，降低跟随上游的维护成本。

受管包内容：
- 锁定版本的 DSH 构建（企业自编译、签名）
- 锁定配置：模型地址只指向企业 AgentGate 网关；MCP 只允许平台下发清单
- 插件白名单：只允许安装能力中枢审核过的插件/技能
- 工作目录沙箱、高危命令前置确认、文件改动备份与整轮回滚（DSH 侧配置）
- 进程级出口守卫规则（见 `endpoint/egress/`）
- 透明加密白名单申请材料：进程名/签名证书指纹/版本清单，供企业安全
  部门在绿盾/天锐等透明加密系统中配置进程白名单

准入自检：对照《企业级防护方案设计》§2.1 的 7 条准入标准逐项验证，
不通过的构建不得申请加密白名单。
